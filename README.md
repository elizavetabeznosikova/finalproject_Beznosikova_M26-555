# ValutaTrade Hub

Учебный проект: консольный симулятор криптовалютного трейдинга на Python.
Пользователь может зарегистрироваться, вести портфель фиатных и криптовалют,
покупать и продавать валюту по актуальным курсам, получаемым из внешних API.

## Возможности

- Регистрация и вход по логину/паролю (пароли хранятся в виде хеша с солью).
- Портфель с кошельками в USD, EUR, RUB, BTC, ETH, SOL.
- Покупка и продажа валют за USD с проверкой баланса.
- Курсы валют: криптопары — через CoinGecko, фиатные — через ExchangeRate-API
  (требуется бесплатный API-ключ).
- Кеширование курсов в `data/rates.json`, история обновлений в
  `data/exchange_rates.json`.
- Просмотр портфеля в таблице: баланс, курс, стоимость в USD, время обновления.
- Логирование действий пользователя в `logs/actions.log`.
- Устойчивость к ошибкам: сбои одного источника курсов не прерывают обновление,
  некорректный ввод не приводит к падению CLI.

## Установка и запуск

Требуется Python 3.12+ и [uv]

uv sync          # установка зависимостей
uv run valutatrade

Настройка API-ключа
Для фиатных курсов создайте файл .env в корне проекта:
EXCHANGERATE_API_KEY=<your_key>
Ключ бесплатно выдаётся на https://www.exchangerate-api.com/. . Без ключа работают криптопары (CoinGecko), фиатные курсы возвращаются заглушкой.

Команды CLI
Команда	Описание
register <user> <pass>	Регистрация нового пользователя
login <user> <pass>	Вход в аккаунт
logout	Выход из аккаунта
show-portfolio	Портфель с балансами и курсами
buy <currency> <amount>	Покупка валюты за USD
sell <currency> <amount>	Продажа валюты за USD
get-rate <currency>	Текущий курс к USD
update-rates	Обновление курсов из внешних API
show-rates	Содержимое кеша курсов
exit	Завершение работы

Пример сессии
>>> register alice 1234
>>> login alice 1234
>>> update-rates
>>> buy BTC 0.01
>>> show-portfolio
